# Json для раздельного (сплит) туннелирования в Amnezia
## Как этим пользоваться?
Для того, чтобы их использовать надо скачать нужные .json файлы отдельно, либо все разом нажав Code -> Download ZIP, либо можно сделать (если есть Git):
```
git clone https://github.com/jirnobruh/Split-Tunneling-Amnezia-for-Russia.git
```
тогда если я буду выпускать обновления конфигов, то через команду
```
git pull
```
можно будет их обновить.

Далее их нужно добавить в приложение AmneziaVPN, для этого:
1) Отключаемся от VPN
2) Заходим в раздел "Раздельное туннелирование"
3) Включаем "Раздельное туннелирование сайтов" 
4) Жмем значок в виде трех точек снизу
5) Импорт
6) Жмем "Добавить импортированные сайты к существующим"
7) Выбираем нужные json файлы
8) Подключаемся к VPN

## Что находится в списке amnezia_split_ru_full
Все российские сайты, которые я думаю, что не должны подключаться к VPN по одной из причин:
1) Не пускают на сайт с включенным VPN
2) Могут сливать данные РКН для блокировок по IPv4 адресам

Если конкретней, то туда добавлены следующие сервисы (включая их поддомены, IP и CDN):
- Госуслуги, ФНС, ПФР и другие государственные порталы (включая региональные вроде mos.ru)
- Инфраструктура Яндекса (ya.ru, yandex.ru, Метрика, Турбо-страницы, облака и CDN)
- Экосистема VK (vk.com, mail.ru, Одноклассники, RuStore, Dzen) и их системы доставки контента (oneme.ru)
- Крупнейшие маркетплейсы (Ozon, Wildberries, Авито, Купер)
- Банки РФ (Сбер, Т-Банк, ВТБ, Альфа-Банк, Райффайзен и др.)
- Телекомы и провайдеры (Ростелеком, МТС, Мегафон, Билайн, Tele2, Дом.ру и др.)
- Транспорт и авиа (РЖД, Аэрофлот, S7, Авиасейлс, СДЭК, Почта России, Тройка)
- Крупный ритейл (DNS, М.Видео, Ситилинк, X5 Group, Магнит, Самокат)
- СМИ, развлечения и ИТ (Кинопоиск, Pikabu, Habr, РИА, РБК, Лента, НГС и городские порталы Шкулев Медиа)
- Обязательные локальные и служебные IP-подсети (10.0.0.0/8, 192.168.0.0/16, CGNAT 100.64.0.0/10, localhost и др.)
В списке оставлены только точечные адреса, чтобы не нарушать работу глобальных сервисов (например, YouTube GGC), размещенных внутри сетей российских провайдеров.

## Что находится в списке amnezia_split_steam (работоспособность проверена!)
Сюда входит всё, что связано со Steam, магазином Valve, а также инфраструктурой CS2 и Dota 2.

*Важный момент по CS2, Dota 2 и другим онлайн-играм:* игровые серверы матчмейкинга используют другие пулы IP-адресов, которых нет в этом списке. Поэтому сами матчи будут идти **через VPN** (пинг будет зависеть от расположения вашего VPN-сервера), а вот скачивание самих игр и гигантских обновлений пойдет в обход VPN на максимальной скорости вашего провайдера без расхода трафика. 

`
ВНИМАНИЕ!
Если вы хотите сменить регион Steam, то сначала надо очистить список сплит-туннелирования и не добавлять данный список!
Как только смените регион - то можно добавлять!
`

Данный конфиг я сделал потому что:
- У некоторых VPS (а иногда и у VPN сервисов) бывает ограничение по количеству трафика и чтобы не тратить его на установку игр со Steam и постоянно не отключать VPN на время скачивания 
- В моем случае сервера Valve в моем городе скорее всего находятся на том же оборудовании, что и сервера моего провайдера, из-за этого при инете 200мбит/с (а раньше 100) у меня скорость 1Гбит/с, а под VPN скорость падает до тарифных, а иногда (особенно на сторонних VPN сервисах) ограничивалась 100 мбит/с.

## Что находится в списке amnezia_split_epicgames (работоспособность не проверена!)
Собственно сюда входит все, что связано с EpicGames, Fortnite, Unreal Engine. Также добавлены:
- Серверы античита Easy Anti-Cheat (EAC)
- Служебные поддомены лаунчера (магазин, библиотека, авторизация)
- Серверы доставки обновлений и CDN (Fastly, AWS, облачные хранилища), откуда качаются сами игры.

`
ВНИМАНИЕ!
Если вы хотите сменить регион Epic Games Store, то сначала надо очистить список сплит-туннелирования и не добавлять данный список!
Как только смените регион - то можно добавлять!
`

*Важный момент по Fortnite:* игровые серверы для матчей используют динамические IP Amazon AWS, которых нет в этом списке. Поэтому сами онлайн-матчи будут идти **через VPN** (что даст вам зарубежный IP и пинг), а вот огромные обновления будут качаться мимо VPN на максимальной скорости.
Делал я его по той же причине, что и Steam - если на VPS есть лок по количеству трафика, то так мы качаем игры напрямую и либо не тратим трафик, либо тратим намного меньше.
